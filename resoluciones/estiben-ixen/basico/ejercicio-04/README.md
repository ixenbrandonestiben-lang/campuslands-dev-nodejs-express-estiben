# Básico 04 — Módulos ES Modules (Battle Royale)

Solución oficial implementada con **ES Modules** (`import` / `export`) en Node.js y Express.

- **Ruta:** `resoluciones/estiben-ixen/basico/ejercicio-04/`
- **Temática:** Battle Royale (Zonas de tormenta y áreas seguras)
- **Tema central:** `"type": "module"`, importaciones explícitas con extensión `.js`.

## Endpoints
- `GET /health` -> Estado del servidor.
- `GET /basico/ejercicio-04` -> Respuesta esperada con `topic: "modulos ES Modules"`.
- `GET /basico/ejercicio-04/zonas` -> Listado de zonas seguras.
- `POST /basico/ejercicio-04/reducir` -> Reduce el círculo de tormenta validando mapa y radio.
