# Básico 30 — Proyecto Integrador Básico (Motos y Mecánica)

Proyecto integrador de nivel básico que agrupa todos los conceptos adquiridos en el nivel:
- Arquitectura en tres capas (`routes`, `controllers`, `services`).
- Persistencia en memoria y mutabilidad controlada.
- Validaciones exhaustivas de parámetros de ruta, cuerpo y consultas.
- Manejo centralizado de errores y middlewares globales.
- Logging y semántica HTTP REST estricta.

- **Ruta:** `resoluciones/estiben-ixen/basico/ejercicio-30/`
- **Temática:** Motos y Mecánica (Gestión integral de órdenes de taller)
- **Tema central:** Integración completa de patrones backend en Node.js y Express.
